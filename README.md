# Dr. Grewal — approval demonstration

Sample website for Grewal Homeo Remedies, Mohali. It is a no-index preview for reviewing Version 1.

Customer enquiries, distributor enquiries, prescription filenames and payment steps stay in browser memory. Refreshing the page clears them. No message, file or payment is sent.

See `docs/content-sources.md` for sources and items that still need confirmation.

```bash
npm install
npm run dev
npm run build
```
